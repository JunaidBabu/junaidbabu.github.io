# Junaid Babu | Digital Portfolio & Tech Blog

A centralized hub for my open-source web applications and engineering blog. Built to prioritize "Web Native" environments, completely static execution, and independence from backend rot.

## Tech Stack
- **Framework**: [Astro](https://astro.build/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Deployment**: Zero-downtime delivery via GitHub Actions & GitHub Pages

## Local Development

```bash
# Install dependencies
npm install

# Start the local server
npm run dev
```

## Production Build

The site automatically deploys on every push to the `main` branch via GitHub Actions.

To build the static artifacts manually:
```bash
npm run build
```
