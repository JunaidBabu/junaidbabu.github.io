About My Approach

Quality software shouldn't require complex infrastructures or expensive proprietary subscriptions to operate smoothly. I focus heavily on "Web Native" solutions.

By utilizing tools like React, Vite, Tailwind CSS, and in-browser AI engines (like Web Speech APIs and Transformers.js), I build software that runs primarily on device hardware. This approach ensures maximum privacy, offline capabilities, and zero hidden costs.

My definitive mission is to convert ideas into products that live forever. By engineering applications that function predominantly on-device and run seamlessly from static environments like GitHub Pages, I build software that avoids backend server rot, eliminates infrastructure dependencies, and remains accessible indefinitely.
